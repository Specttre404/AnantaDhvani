# Contributing to Ananta Dhvani

Thank you for your interest in contributing to **Ananta Dhvani** (अनन्त-ध्वनि / অনন্ত ধ্বনি)!

### Project Status: Active Testing Phase
Ananta Dhvani is an independent passion project created by **Ishan** using **Google Gemini 4 Argon**, forked from **LastWave** (`dkanada/lastwave`). The project is in an active testing and architectural hardening phase.

### Contribution Guidelines
1. **Branching**: Branch off `main`. Prefix pull requests with standard conventional commits (`feat:`, `fix:`, `docs:`, `refactor:`, `perf:`).
2. **Audio Purism**: Pull requests that add spoken-word feeds, podcast directories, tracking SDKs, or cloud leveling will be rejected.
3. **UI Standard**: All new UI components must conform to Material 3 Expressive and iOS Liquid Glass translucent refraction standards.
4. **Verification**: Verify that `gradlew app:compileReleaseKotlin` and `gradlew app:test` pass with zero failures before submitting PRs.
