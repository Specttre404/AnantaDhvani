# Security Policy

## Supported Versions
| Version | Supported | Status |
| :--- | :--- | :--- |
| **v1.6.x-HDR** | Yes | Active Testing & Hardening |
| < v1.6.0 | No | Deprecated |

## Reporting a Vulnerability
Ananta Dhvani operates under zero-telemetry and cleartext-disabled security principles. If you discover a potential vulnerability (e.g., memory leak, insecure local storage caching, or cryptographic flaw):
1. **Do not open a public GitHub issue.**
2. Send report details directly via GitHub Security Advisories or contact Ishan on Twitter/X (`@Ishan___404`).
3. You will receive an initial response within 48 hours. Validated fixes will be deployed in the next `-HDR` release cycle.
